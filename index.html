Train the eye · memory generation
DDR3
Skip for this buy
R720 / R730-era older sticks. Wrong notch. Will not seat in R640 / R740xd / R750. Cheap, hot, dead end for local LLMs.
DDR4 ECC RDIMM
R640 · R740xd · R750 live here
Registered ECC only. 2666–3200 MT/s typical. This is what the $250 Samsung 64 GB stick is. Not SO-DIMM. Not desktop UDIMM.
DDR5 ECC RDIMM
R760 / DL380 Gen11 / new only
Will not go in an R740xd. Premium and scarce. Only if you jump a generation and blow the $1,500 cap.
RULE · sticks must match the chassis generation DDR4 RDIMM → R640 / R740xd / R750. DDR5 RDIMM → R760+. DDR3 → leave on the table.
